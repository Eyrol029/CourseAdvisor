# CourseAdvisor: Academic Planner
Mobile Architecture & System Design Specification (BEEd - Mindanao State University at Naawan)

CourseAdvisor is an intelligent, offline-first mobile academic planning application designed for Bachelor of Elementary Education (BEEd) students at Mindanao State University at Naawan (MSUN).

## Features
- **Curriculum Tracking:** Complete official 167-unit prospectus across 10 terms with prerequisite tracking.
- **Goal-Driven Backward Chaining:** Resolves graduation trajectories recursively from Capstone (`ELC 197`).
- **Kahn's Topological Sorter:** Cycle detection and levelization DAG traversal.
- **Mamdani Fuzzy Logic Inference:** Dynamic workload & stress index modeling based on course difficulty and student confidence.
- **Interactive Dual-Mode Roadmap:** Semester plan accordion view & Prerequisite DAG graph with road line connections.
- **Offline-First Storage:** Local database and persistent storage.
